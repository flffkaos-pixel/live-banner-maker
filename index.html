상품 URL을 넣고 버튼 하나만 눌러줘. 이미지·문구 수집부터 1080×1920 합성까지 자동.

🖐 이미지 직접 넣기 — 개발자도구 URL 붙여넣기 / 다운로드한 파일 올리기 (서버 없이도 OK)
① 상품 페이지에서 상세까지 스크롤 → 이미지 우클릭 → 이미지 주소 복사 → 아래에 한 줄에 하나씩 붙여넣기
② 또는 다운로드(또는 드래그)한 이미지 파일을 선택
🤖 프록시도 막히면? 상품 페이지에서 상세이미지 직접 가져오기 (봇차단 원천 우회)
✅ 제일 확실한 방법 (추천): 로컬 추출기
폴더 안 extract.py를 이렇게 실행하면 진짜 크롬이 열려서 상세·이벤트이미지까지 긁어와:
python "live-banner-maker\extract.py" "상품URL"
끝나면 이 페이지 새로고침 → 이미지 자동 로드!
1. 아래 버튼을 즐겨찾기 바로 가기로 드래그해둬 (딱 한 번만): 📌 스튜디오로 보내기
2. 네이버 상품 페이지에서 상세설명까지 스크롤로 한 번 쭉 내린 뒤 → 즐겨찾기 버튼 클릭!
3. 이미지 N장이 새 탭 스튜디오로 전송돼 → 상세이미지까지 그대로 배너로 쓰면 끝.
원리: 네가 직접 연 페이지는 봇차단이 안 걸려. 그 페이지 안에서 이미지를 긁어오는 방식이라 상세(se-viewer) 이미지까지 다 들어와. 깃헙의 크롬확장 이미지추출기와 같은 원리야.
